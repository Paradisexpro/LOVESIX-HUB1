LOVE SIXHUB — เว็บไซต์ขายไอดีเกม (โปรเจกต์สาธิต)
=================================================

วิธีเปิดใช้งาน
--------------
1. แตกไฟล์ zip ทั้งหมด
2. เปิดไฟล์ index.html ด้วยเบราว์เซอร์ได้ทันที (ไม่ต้องติดตั้งอะไรเพิ่ม)
   หรือถ้าต้องการรันผ่านเซิร์ฟเวอร์เล็กๆ ก็ใช้คำสั่ง (มี Python):
     python3 -m http.server 8000
   แล้วเปิด http://localhost:8000

ระบบข้อมูล
----------
เว็บนี้เก็บข้อมูลทั้งหมด (สินค้า, สมาชิก, ออเดอร์, โค้ดต่างๆ) ไว้ใน
Firebase Realtime Database ของโปรเจกต์ `lovesixshop` สามารถเข้าถึงได้จาก
ทุกเครื่อง/ทุกเบราว์เซอร์พร้อมกัน (ข้อมูลจะแชร์ร่วมกันทั้งระบบ)

ก่อนใช้งานครั้งแรก ต้องไปตั้งกฎ (Rules) ของ Realtime Database ที่
Firebase Console > Realtime Database > Rules ให้อนุญาตอ่าน/เขียน
แบบสาธิต (แล้วค่อยเพิ่มระบบยืนยันตัวตนจริงทีหลัง) เช่น:

  {
    "rules": {
      ".read": true,
      ".write": true
    }
  }

ถ้า Firebase อ่าน/เขียนไม่ได้ เว็บจะสำรองข้อมูลไว้ใน localStorage ของเบราว์เซอร์
เพื่อให้ยังใช้งานได้ (ดูใน console ของเบราว์เซอร์สำหรับคำเตือน)

(แก้ไขได้ภายหลังในหน้า หลังบ้าน > ตั้งค่า)

โค้ดเติมพ้อยตัวอย่าง (ใช้ในหน้า "เติมพ้อย")
--------------------------------------------
WELCOME100 → +100 พ้อย
GAMER500   → +500 พ้อย

ฟีเจอร์หลัก
-----------
- สมัครสมาชิก / เข้าสู่ระบบ / เปลี่ยนรหัสผ่าน
- ระบบพ้อย ใช้ซื้อสินค้า และเติมพ้อยผ่านโค้ด
- ร้านค้าแบ่งตามหมวดหมู่เกม พร้อมค้นหาสินค้า
- ซื้อไอดีเกม → ระบบตัดพ้อยและส่งรหัสบัญชีให้ทันที
- หน้าโปรไฟล์แสดงประวัติการซื้อทั้งหมด
- หลังบ้านแอดมิน (ต้องกรอกรหัสแอดมินก่อนถึงจะเห็นเมนู) จัดการได้ครบ:
    • เพิ่ม/แก้ไข/ลบสินค้า และจัดการสต๊อกรหัสไอดีของแต่ละสินค้า
    • เพิ่ม/ลบหมวดหมู่สินค้า
    • สร้าง/ลบโค้ดเติมพ้อย
    • จัดการสมาชิก: ปรับพ้อย, ตั้งรหัสผ่านใหม่ให้ลูกค้า, ระงับ/ปลดระงับบัญชี,
      เลื่อน/ลดสิทธิ์แอดมิน, ลบบัญชี
    • ดูประวัติคำสั่งซื้อทั้งหมดในระบบ
    • ตั้งค่าชื่อเว็บไซต์และรหัสแอดมิน, รีเซ็ตข้อมูลทั้งหมด
